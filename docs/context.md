## 1. What We Are Building
An end-to-end AI-powered decision-support system for motor insurance underwriters. Given an Indian Driving License Number (e.g. `MH4720231551327`), the application:
1. Validates the 15-character driving license format (`^[A-Z]{2}\d{2}\d{4}\d{7}$`).
2. Looks up the customer record from MongoDB (with in-memory fallback to `data/customers_db.json`).
3. Cleans the data and deterministically computes derived facts (claims/year, vehicle risk class, age/experience bands, fresher status, NCB).
4. Predicts continuous risk score (0–100), tier (`low`, `medium`, `high`), probabilities, and top 5 risk drivers via the live Python FastAPI ML service (`rf_insurance_model.pkl` 300-tree Random Forest Regressor).
5. Computes exactly 5 canonical indicator cards (`vehicle`, `claims`, `violations`, `driver`, `history`) with rule-based severities and text.
6. Generates a concise, strictly grounded underwriter summary (headline, narrative, recommendation) via live LLM (Google Gemini `gemini-3.5-flash-lite`) with JSON mode and deterministic template fallback if offline.
7. Renders the complete profile in a professional React + Tailwind dashboard in ~2.1s (well below the 20s requirement).

## 4. How to Run All Services

### 1. ML Service (FastAPI — when ML_MODE=remote)
- **Needed when**: `backend/.env` has `ML_MODE=remote`. The backend calls `http://127.0.0.1:8000/predict` on each request.
- **Command to run**:
  ```bash
  cd ml-service
  python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
  ```
- **Optional Standalone Mode**: If you don't want to run the Python process, switch `ML_MODE=mock` in `backend/.env`. The backend will use its internal rule-based scoring engine without needing the Python service.

### 2. Backend (Express)
```bash
cd backend
npm run dev    # runs on http://localhost:5000
```

### 3. Frontend (React)
```bash
cd frontend
npm run dev    # runs on http://localhost:5173
```

## 5. Database & MongoDB Compass Reference
- **Connection URI**: `mongodb://127.0.0.1:27017/insurance`
- **Compass Access**: Open MongoDB Compass, connect to `mongodb://localhost:27017`
- **Database**: `insurance`
- **Collection**: `customers` (10,000 documents)
- **Primary Indexes**:
  - `_id_`: default MongoDB ObjectId
  - `driver.driving_license_number_1`: unique index for fast lookups
- **Fallback**: If MongoDB is stopped, `customer.service.js` automatically uses the in-memory parsed `data/customers_db.json`.
